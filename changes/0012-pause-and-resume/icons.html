The buttons of a reading

The drawings from which the human chose the icons of unit 0012: the green person speaking for "Read Aloud", the person with a line in front for "Resume Reading", IntelliJ's own pause and stop, and a grey background behind the group in every state. The page opens on those choices. A person speaking for "Read Aloud", IntelliJ's own pause and red stop while a file is read, and the person again, with or without a line in front, for "Resume Reading" while it is paused. The switches below set the color of Read Aloud, the resume icon and how the buttons of a reading are grouped. Each frame has IntelliJ's Run and Stop in the main toolbar, as if runIde is running, so the two stops can be compared. The IDE colors are fixed, whatever theme this page shows.

The icons on their own

Enlarged to 32 px on the tab-row grey of both IDE themes. Only the person icons are drawn for the plugin. The others are IntelliJ's own (expui/run/*), included for comparison.

Things to look for

  • At 1×, does the person say "read this aloud" rather than "account"?
  • A green person on every Markdown tab: does it look like a button to press, or like noise next to the grey layout icons?
  • At 1×, does the line read as "carry on from here", and is the person still recognizable beside it?
  • Is the red stop on the tab clearly about the reading, given that it sits next to the head or pause, while the toolbar stop sits next to the run configuration?
  • In the dark theme, does the green icon stay calm enough next to the grey layout icons?
